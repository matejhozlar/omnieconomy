## Features

- 💵 Physical currency system with 8 denominations
- 🏧 ATM blocks for banking
- 🎮 Player commands for money management
- 🎁 Daily rewards and playtime income
- 👹 Configurable mob drops
- ✨ Custom Capitalist Greed enchantment
- 🎲 Server-wide lottery system
- 🔧 Create mod integration (Stock Ticker support)
- ⚙️ Highly configurable
- 💾 Automatic backups

## Installation

1. Download from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/omnieconomy) or [Modrinth](https://modrinth.com/mod/omnieconomy)
2. Place the `.jar` file in your `mods` folder
3. Launch Minecraft with NeoForge 21.1.213+

**Minecraft Version**: 1.21.1
